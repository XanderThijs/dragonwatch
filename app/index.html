Monster pool

    Predicted by a model trained on simulated fights (the Encounter lab); every result is also checked by a live simulation. It is a planning aid for a simplified version of D&D, not a promise. Everything is added to combat with initiative rolled; Undo takes it back.

    Import encounter

    One creature per line: [count]x Name | hp 7 | ac 15 | init +2. Optional: roll 14 (a fixed initiative total instead of rolling), type npc, temp 5, lr 3 (legendary resistance), la 3 (legendary actions), recharge Fire Breath 5, uses Spellcasting 3, note …. Lines starting with # are the title. JSON works too.

    Abilities

    Legendary actions refresh at the start of the creature's turn. Spent recharge powers are rolled for automatically at the start of its turn (or press Roll d6).
